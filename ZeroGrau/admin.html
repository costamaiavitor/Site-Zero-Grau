Como funciona. O que você muda aqui vira um rascunho, salvo sozinho, e as duas lojas neste navegador já mostram o resultado, com um aviso de prévia. Os clientes só veem depois de Publicar: o botão baixa o arquivo ajustes.js, que vai para a pasta ZeroGrau/js/ do repositório. Este painel ainda não tem senha — sem servidor, ele só consegue mexer no navegador de quem o abre.

Arquivo pronto

O navegador baixou ajustes.js. Para os clientes verem as mudanças:

  1. No GitHub, abra a pasta ZeroGrau/js/ do repositório.
  2. Add file → Upload files, solte o ajustes.js e confirme o commit na main. Ele substitui o que está lá.
  3. Em um ou dois minutos o site é publicado. Quem esteve nele nos últimos dez minutos pode demorar esse tanto para ver.
  4. Quando o arquivo estiver no ar, o painel percebe sozinho que o rascunho ficou igual ao publicado e o apaga.
