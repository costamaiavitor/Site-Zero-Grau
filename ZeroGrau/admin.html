Como funciona. O que você muda aqui vira um rascunho, salvo sozinho, e as duas lojas neste navegador já mostram o resultado, com um aviso de prévia. Os clientes só veem depois de Publicar. Com a chave do GitHub conectada (aba Publicação), o botão grava direto no site, que se atualiza em um ou dois minutos; sem ela, o botão baixa o arquivo ajustes.js para você subir à mão.

Publicação

Publicar direto no GitHub

Não conectado. Publicar baixa o arquivo para você subir à mão.

A chave fica guardada só neste navegador. Em computador compartilhado, use "Esquecer a chave" ao terminar: com ela, qualquer um que abrir este painel aqui consegue publicar.

Como criar a chave (uma vez só)
  1. No GitHub, entre com a conta dona do site e abra Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: "Painel Zero Grau". Expiration: o prazo que preferir — quando vencer, é só gerar outra.
  3. Repository access: Only select repositories → Site-Zero-Grau. Só ele.
  4. Permissions: clique em + Add permissions, marque Contents e, na linha que aparece, troque para Read and write. Não precisa de mais nada (o Metadata · Read-only que o GitHub põe sozinho pode ficar).
  5. Generate token, copie o código (começa com github_pat_) e cole aqui ao lado.
Sem a chave

Dá para publicar à mão a qualquer momento: baixe o arquivo e suba em ZeroGrau/js/ no GitHub (Add file → Upload files).

Falta conectar o GitHub

Para o Publicar gravar direto no site, cole uma vez a chave de acesso do GitHub na aba Publicação. O passo a passo está lá e leva uns dois minutos.

Arquivo pronto

O navegador baixou ajustes.js. Para os clientes verem as mudanças:

  1. No GitHub, abra a pasta ZeroGrau/js/ do repositório.
  2. Add file → Upload files, solte o ajustes.js e confirme o commit na main. Ele substitui o que está lá.
  3. Em um ou dois minutos o site é publicado. Quem esteve nele nos últimos dez minutos pode demorar esse tanto para ver.
  4. Quando o arquivo estiver no ar, o painel percebe sozinho que o rascunho ficou igual ao publicado e o apaga.
